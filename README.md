# Барная карта

Сайт для поиска коктейля по вкусу, крепости и настроению. Есть ещё черновик конструктора с сочетаниями ингредиентов и страница замен основ и ликёров.

## Запуск

```powershell
python -m http.server 8765 --directory site
```

Затем откройте http://localhost:8765. Можно и просто открыть `site/index.html` двойным кликом: данные лежат в JS-файле, поэтому сервер не обязателен.

## Обновление данных

1. Обновите CSV в корне (`cocktails.csv`, `cocktail_descriptions.csv`, `cocktail_ingredients.csv`). Например, через `python src/build.py .`.
2. Пересоберите данные сайта:

   ```powershell
   python src/export_site_data.py
   ```

   Скрипт перечислит ингредиенты, которых ещё нет в словаре.
3. Добавьте новые ингредиенты в `data/ingredient_map.csv`:
   - `raw` — имя ингредиента как в рецепте;
   - `canonical` — базовый ингредиент для подсчёта сочетаний (несколько разделяются через `|`, например `Соль|Чили`);
   - `category` — категория в списке конструктора.

## Замены

`data/substitutions.csv` содержит колонки:

- `ingredient` — базовый ингредиент, как в колонке `canonical` словаря;
- `substitute` — чем его заменить (если это известный ингредиент, на него можно будет перейти);
- `level` — насколько близка замена: `1` почти без потерь, `2` заметно иначе, `3` в крайнем случае;
- `note` — что изменится во вкусе и как поправить пропорции.

Экспорт предупредит, если в `ingredient` указано имя, которого нет в рецептах.

## Безалкогольные коктейли, шоты, вариации

- Безалкогольные: `strength = безалкогольный`, `base_spirit = безалкогольный`. На сайте они показываются серым с подписью «0%». Экспорт также понимает синонимы: «без алкоголя», «0%».
- Шоты: `family = Шот` и тег `шот` в `extra_tags`. Бокал «шот» рисуется отдельным силуэтом.
- Цвета крепости: безалкогольный — серый, лёгкий — зелёный, средний — жёлтый, крепкий — красный.
- Вариации из `cocktail_variations.csv` показываются в карточке коктейля. Ингредиенты вариаций (строки с заполненным `variation_id`) не попадают в базовый рецепт и в подсчёт сочетаний.

## Справки об ингредиентах

`data/ingredient_info.csv` (`name,abv,made_from,taste`) — крепость, из чего сделан и вкус
для каждого базового ингредиента (имя — как в `canonical` из `ingredient_map.csv`).
По клику на ингредиент в составе коктейля (и на ⓘ в «Заменах», «Конструкторе», «Моём баре»)
открывается карточка. Экспорт предупредит, если у нового ингредиента нет справки;
английский текст — через `src/i18n_tool.py todo` (файл `todo_ingredient_info.json`).

## Мой бар

Отмечаете, что есть дома, — сайт показывает, что из этого можно сделать.
Весь алкоголь рецепта должен быть в наличии; безалкогольных ингредиентов может
не хватать до трёх (пометка «докупить»). Режим «Только алкоголь» учитывает
только бутылки. Вода, лёд, сахар, сахарный сироп и соль считаются доступными
всегда; фрукт засчитывает свой сок (лайм → сок лайма), игристое = шампанское.
Списки правок — `BASICS` и `IMPLIES` в `site/js/mybar.js`; выбор хранится в браузере.

## Языки (RU / EN)

Язык выбирается по браузеру: русский для ru/uk/be/kk, иначе английский. Его можно сменить глобусом в шапке, выбор запоминается. Русский — исходный язык данных. Если перевода нет, показывается русский текст.

- Строки интерфейса лежат в `site/js/i18n.js` (словарь `UI`). Новый язык: добавить его в `LANGS` и `UI`, а в `src/export_site_data.py` — в `LANGS`.
- Переводы данных лежат в `data/i18n/en/`:
  - `terms.json` — теги, бокалы, методы, единицы, категории;
  - `ingredients.json` — названия ингредиентов;
  - `cocktails.json`, `variations.json`, `substitutions.json` — тексты. Ключ `h` — отпечаток русского текста: если исходник изменится, перевод считается устаревшим.
- После добавления коктейлей:

  ```powershell
  python src/i18n_tool.py todo --chunks 3
  ```

  Скрипт сложит непереведённое в `data/i18n/_work/todo_*.json`. Переведите их в `done_*.json` (формат описан в начале `src/i18n_tool.py`), затем:

  ```powershell
  python src/i18n_tool.py merge data/i18n/_work/done_*.json
  python src/export_site_data.py
  ```

  Экспорт пишет, сколько осталось непереведённого.

## Фото

Положите файл `site/images/<id>.jpg` (подойдут также `.png` и `.webp`), где `<id>` — это id коктейля из CSV, например `negroni.jpg`, и перезапустите экспорт. Пока фото нет, вместо него показывается силуэт бокала: форма зависит от типа бокала, цвет — от вкуса.

## Структура

```
site/index.html       — поиск: строка поиска, панель тегов, карточки, модальное окно
site/builder.html     — конструктор: ингредиенты по категориям, схема сочетаний, набор
site/substitutes.html — замены основ и ликёров с пояснениями
site/mybar.html       — «Мой бар»: что можно сделать из того, что есть
site/css/style.css    — тёмная барная тема
site/js/i18n.js       — языки: словарь интерфейса, переключатель-глобус
site/js/common.js     — данные, переводы данных, плейсхолдеры, модальное окно
site/js/search.js     — логика поиска и фильтра (все выбранные теги одновременно)
site/js/builder.js    — подсчёт сочетаний и схема
site/js/subs.js       — страница замен
site/js/mybar.js      — подбор по наличию (правила и списки — в начале файла)
site/favicon.svg      — иконка сайта
site/data/data.js     — генерируется src/export_site_data.py
data/ingredient_map.csv — словарь синонимов ингредиентов
data/substitutions.csv  — замены ингредиентов
data/i18n/en/*.json     — английские переводы данных
src/i18n_tool.py        — поиск непереведённого и слияние переводов
```
